# Image library — backgrounds for future posts

Photos Pedro generated (2026-10-09) to use as post backgrounds. All are 900×1500 portrait PNGs, dark/night-stadium mood, no club crests or real players.

Use with `make_post.py` as `"bg": "library/<file>"` (adjust `bg_y` to frame the subject). For a post that needs Instagram's 4:5 crop, the script resizes and crops automatically.

| File | Shows | Good for |
| :-- | :-- | :-- |
| `01_penalti.png` | Ball on the spot, keeper on the line, floodlights | Pênaltis, decisões, "você bate ou escolhe o cobrador?" |
| `02_tatica.png` | Coach drawing a formation on a tactics board | Formações, BEST XI, Dica do técnico, escalação |
| `03_transferencia.png` | Handshake over a signed contract, stadium behind | Mercado / janela de transferências, propostas de emprego |
| `04_vestiario.png` | Locker room, shirts 10 and 9 hanging | Vestiário, elenco (11–22 jogadores), moral, quotes |
| `05_entrada_em_campo.png` | Players walking out of the tunnel into the stadium | Início de temporada, novidades, "bora jogar" |
| `06_trofeu.png` | Trophy lifted with confetti | Título, conquistas, campeão da Divisão 1 |
| `07_promocao.png` | Stadium stairs with gold up-arrows | Acesso / promoção, 4 divisões, subir de divisão |
| `08_chute.png` | Close-up of a boot striking the ball | Gols, motor de partida, notas dinâmicas, artilheiros |
| `09_torcida.png` | Fans celebrating with flags and confetti | Engajamento, enquetes, vitórias, moral do técnico |
